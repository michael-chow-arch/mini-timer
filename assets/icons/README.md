# UI icons

The four SVGs in this directory are unmodified assets from [Phosphor Icons core 2.1.1](https://github.com/phosphor-icons/core), distributed under the included MIT license.

- Bold: pencil-simple, arrow-counter-clockwise (filenames omit the weight suffix)
- Fill: play, pause

They are bundled locally so the timer remains fully offline. CSS inverts the black assets for white controls.
